# Jetson を鉢に入れる案を見送った記録

- 日付: 2026-11-16（ハード担当 syon.oba の検討。Claude Code と一緒に整理した）
- 関係するもの: 仕様書 [§3 構成](../superpowers/specs/2026-11-13-futamaru-agent-design.md)、GPU の PC [#37](https://github.com/menter-Hackathon/team4/issues/37)

## 何を比べたか

- **A 案（今の案）**: ESP32 は耳と口だけ。音声をクラウドに送り、GPU のある PC かクラウドで「文字起こし（STT）→ 返事を考える（LLM）→ 声にする（TTS）」を行う
- **B 案**: GPU 付きの小さいコンピューター Jetson を鉢に入れ、LLM（小さい Gemma 4）と STT（kotoba-whisper）を植物の中で動かす。TTS はクラウドのまま

## 結論

**A 案のまま進める。** Jetson は使わない。「植物の中で考える」は、発表で今後の展望として話す。

## 理由

1. **値段に見合わない**: Jetson は数万円で、ESP32 の何倍もする。それでも TTS はクラウドなのでネット接続はなくならず、「植物だけで動く」とは言えない
2. **性格が育つ仕組みが小さいモデルで動くかわからない**: ふたまるの売りは、性格と記憶が育つこと。記憶は全部ではなく「大事な記憶 10 件と前回の要約」だけをプロンプトに入れる作りなので（仕様 §6）、文脈の長さは一番の問題ではない。難しいのは次の 2 つで、Jetson で動く小さいモデル（Gemma 4 E2B / E4B）で崩れずにできるかがわからない
   - 4 つの性格の値に合わせて話し方を変えること
   - 会話のあとに、記憶と性格の変化を決まった形（JSON）で書き出すこと（§6.3）
3. **あとから広げやすいのはサーバー**: 記憶の DB がサーバーにあれば、複数の株、成長のグラフ、バックアップ、モデルの入れ替えがしやすい
4. **締め切りに間に合わない**: 11/18 に買って 11/20 が締め切り。OS の書き込み、モデルの準備、速度と性格の動きの確認に 2 日では足りない
5. **ハードの負担が大きい**: Jetson は 7〜25W を使い、専用の AC アダプターが要る。開発キットは約 10cm 角でファンも付いている。土と水のある鉢に入れるには、筐体を作り直すことになる

## 補足

「クラウド」には、チームの GPU の PC で Gemma 4 を動かす方法（#37）と、OpenAI などの API を使う方法がある。A 案はどちらでも成り立つ。GPU の PC が見つからなければ、OpenAI で代わりに動かす（#37 に記載）。
