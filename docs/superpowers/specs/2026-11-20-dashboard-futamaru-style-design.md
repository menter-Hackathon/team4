# ダッシュボードの見た目をふたまるの世界観にそろえる（設計メモ）

- 作成: 2026-11-20
- 対象: `scripts/dashboard.html`（仕様 §6.6、#59）
- 大きさ: 小さな変更（HTML 1 枚の見た目だけ）

## なぜ

今のダッシュボードは白いカード・標準の Chart.js・「おしゃべり度 0.55」のような数字が並ぶ管理画面の見た目で、
「ただ喋る bot」に見えてしまう。ちゃむさんのイラスト（クリーム色の鉢・茶色の太い線・ほっぺの赤み・丸いかたち）と
画面の雰囲気がそろっておらず、ふたまるがキャラクターとして感じられない。
発表では画面共有で審査員に見せるので（`docs/demo-day.md`）、ショーンさんのふたまる・ちゃむさんのふたまるの
2 体が、それぞれキャラクターとして並んで見えるようにしたい。

見た目の方向性の案（絵本・育成ゲーム・日記）はチームに共有した: https://claude.ai/artifact/LgsJL5XV2eSjicjUNvsnBe
今回はそのうち「中身は今のまま、見た目をきれいにする」を選んだ。

## ゴール

- 画面全体の色・線・文字・角の丸さを、ちゃむさんのイラストにそろえる
- タイプのイラストを大きくして、カードの主役にする
- グラフ（レーダー・成長曲線）も同じ色合いにそろえる
- 発表で使う Windows の PC（ショーンさんの PC）でも同じ見た目で出る

## やらないこと

- 出す情報を変えない（タイプ・レーダー・成長曲線・4 軸の数値・記憶 10 件・前回の要約・方言・振り返った回数・タブ・3 秒ごとの更新）
- `scripts/dashboard.py` と `/api/state` の JSON を変えない。エージェント側（プロンプト・振り返り）にも触らない
- 吹き出し・ことばでの性格表示・日記（案 A〜C の新しい要素）は今回入れない。入れるなら別の PR

## こうなったら失敗

- 発表の PC で文字化け・レイアウト崩れが出る、イラストやグラフが出ない
- 3 秒ごとの更新でちらつく・タブが勝手に切り替わる（今の動きが壊れる）
- 記憶や要約を HTML として入れてしまう（今は textContent で入れている。これは守る）

## 制約

- ライブラリを増やさない。Chart.js 4.4.1（CDN）はそのまま
- 127.0.0.1 だけで待ち受ける・DB は読むだけ、は変えない
- `tests/scripts/test_dashboard.py` は `/` の HTML に「ふたまる」が入っていることを見ている。これは満たしたままにする

## 作り方の案

| 案 | 中身 | 良いところ | 気になるところ |
|---|---|---|---|
| **1. CSS を書き直す（採用）** | `dashboard.html` の `<style>` と、Chart.js の色・文字の指定を書き換える。HTML の組み立て（JS）はほぼそのまま | 依存が増えない。`dashboard.py`・Docker・テストに手が入らない。差分が小さくレビューしやすい | 将来大きく作り変えるときは、また書き直しになる |
| 2. Tailwind + Alpine.js（CDN）で組み直す | HTML をほぼ全部書き直す | この先いじり続けるなら楽 | CDN の依存が 2 つ増える。初めて見るメンバーには読みにくい。差分が大きい |
| 3. React など（Vite でビルド） | フロントを別プロジェクトにする | 部品化しやすい | Node とビルドが増える。「中身はそのまま」には大きすぎる |

1 を選んだ。中身は変えないので、見た目だけを直す一番小さい方法でよい。

## 決めたこと

- 色はイラストから取る: クリーム色の背景、茶色の線と文字、差し色にほっぺのピンクと葉っぱの緑
- 2 株の色分け（今は緑と茶）は残し、イラストの色合いの中で見分けられる 2 色にする
- 文字は丸ゴシック。Google Fonts から読み、読めないとき用に Mac・Windows にある字体を後ろに並べる
  （発表の PC は LiveKit Cloud と Chart.js の CDN を使うのでネットにつながっている）

## 作る人に任せること

- 具体的な色の値、文字の大きさ、余白、角の丸さ
- Google Fonts のどの丸ゴシックにするか（例: M PLUS Rounded 1c、Zen Maru Gothic）
- カードの中の並び（イラストを上に大きく出すか、左に置くか）。ただし出す情報と順番は今と同じ
- スマホ幅（720px 以下）での並べ方
