# 性格の16タイプのイラスト（#64）

ダッシュボード（`scripts/dashboard.py`）に出す「〇〇ふたまる」のイラストを置くフォルダです。

- ファイル名は **英語名.png**（下の表）。名前が違うと表示されません
- 正方形・背景透過の PNG
- まだ置いていないタイプは、ダッシュボードに絵文字が出ます。描けたものから1枚ずつ置いて大丈夫です
- ダッシュボードを開いたまま置いても、3秒以内に絵に切り替わります
